# 风格访谈问题库

参考方向确定或用户明确跳过参考选择后使用。参考可以来自截图选型、用户指定或已有风格。先读取已知布局，不再重新询问相同的导航、首屏或内容排列。一次只问一题，优先补齐对成品影响最大的未知项；不是固定问卷，不要求问满。每题只决定一件事，选项随业务和参考信息变化。

实际提问遵循[提问格式](question-format.md)：标明单选、多选或确认，题干与各编号选项分行展示，并说明如何回复。下文表格与场景只提供问题内容，不直接作为最终提问排版；确认时明确列出“同意”与“不同意，需要修改”两个选项及同意后的动作。

单选、多选按[提问格式](question-format.md)中的选项完整性要求尽可能展开适用方向，每项说明具体效果或适用场景。下文示例中的两三个方向不是数量上限；结合当前业务补全有意义的选项，不机械复用示例，也不加入无关选项凑数。

## 如何开始

先说明从参考中提炼的气质。例如用户选了暖色编辑风格，就问“最想保留它的杂志排版、温暖配色，还是图片氛围？”，不要让用户再选一次完全不同的风格。

用户跳过参考且整体感觉仍不明确时，用场景提问：“你希望访客进入后，更像走进哪种地方？”选项需解释视觉结果，例如：

- 独立杂志：大胆标题、大幅图片、错落有序的网格。
- 安静书店：温暖纸色、舒展留白、柔和材质。
- 未来实验室：冷静底色、精密网格、清楚的数据表达。

这些只是问法示例，不能每个业务都复用同样三个场景。

## 按需选择下一题

| 未知偏好 | 单题示例 | 影响的设计 |
|---|---|---|
| 业务优先级 | “首页优先找队友、聊天消息，还是语音房？” | 内容层级、主要入口与首屏焦点 |
| 情绪与个性 | “除了复古，还希望让人感到亲切、热血，还是神秘？” | 色温、对比、形状和文案语气 |
| 反感的套路 | “最不想看到通用渐变卡片、过度装饰，还是冷冰冰的工具感？” | 明确排除的视觉语言 |
| 视觉主角 | “第一眼应记住大胆标题、原创插画，还是独特材质？” | 主要记忆点、图片资源与空间分配 |
| 排版节奏 | “更喜欢展览式留白，还是杂志式丰富紧凑？” | 网格、内容密度、层级和留白 |
| 配色关系 | “这个方向更偏温暖低饱和，还是少量高对比亮色？” | 主辅色关系与强调方式 |
| 图片语言 | “更喜欢真实摄影、手绘插画，还是抽象图形？” | 只在需要图片时确定其语言 |
| 动效性格 | “动效希望安静克制，还是增加一点有趣反馈？” | 动效节奏与强度 |
| 个人元素 | “有没有希望融入的个人符号或品牌元素？” | 专属细节与避免雷同 |

## 停止与确认

整体气质、业务重点、主要记忆点和影响方案的关键偏好明确后，停止提问。

给出一份简短定义：一句话概念、布局、配色、字体、图像/材质、动效、1–2 个记忆点和避免事项。标明用户已选与设计建议，再只问一个确认问题。用户已有明确授权时不要重复确认；用户要求跳过时沿用主流程分支。

实现中发现次要未决项自行处理；不要把每个圆角、色号、间距都变成新问题，也不要把当前项目偏好写成其他项目的固定默认值。
