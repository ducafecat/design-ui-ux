# 浏览器验收与交付

实现完成后或用户要求审查时读取，只检查本次范围。审查既有工程时沿用其运行方式；仅默认单文件交付需要空目录与 file:// 验证。

逐项检查适用内容；不适用时说明理由，无法完成时记录限制。不要只复制勾选清单作为“已验证”的证据。

- [ ] **流程**：目标端有依据；6 个不同样稿的真实截图、可用的选型预览页和用户选择有记录，或用户明确跳过；风格定义已确认或明确免确认。
- [ ] **选型页**：参考选择未被跳过时，`preview.html` 自包含地展示本批 6 个不同候选及编号，内嵌截图实际加载成功，放大、选择标记与来源链接已验证；换批记录保留。
- [ ] **文件**：最终交付一个自包含 HTML；全部功能视图与样式说明内置，CSS、脚本、JSON 数据与记录、图片及演示媒体均内嵌；不依赖其他 HTML 或资源文件，未覆盖无关作品。
- [ ] **运行**：仅将该 HTML 复制到空目录后双击打开；素材能解码、样式有效，核心演示无非预期外部请求，无本次实现产生的控制台错误或失败资源；记录实际文件大小。
- [ ] **布局**：移动端至少验证 375px、430px 与横屏；PC 端至少验证 1024px、1440px；两端均需则全部验证。记录实际视口，检查横向溢出、遮挡、长文本与缩放。
- [ ] **视觉**：正文、次要文本和按钮的实际前景/背景对比满足详细规范；字号、图标、间距和强调色一致，不用微小正文换取首屏容纳更多内容。
- [ ] **交互**：在单文件内逐个走通关键导航、按钮、筛选、搜索、表单及弹窗；验证反复切换、浏览器返回、路由刷新和深链接，无意外跳转到其他 HTML；覆盖实际存在的空结果、错误、禁用、关闭返回与存储限制。
- [ ] **可访问性**：检查键盘顺序、可见焦点、弹窗焦点恢复、输入标签、图标按钮名称、触控命中区与减少动态效果；不宣称未经专业审计的完整合规。
- [ ] **一致性**：逐项对照实际 CSS 变量、字号、断点与组件状态，确认样式说明与设计稿相符，并能在同一 HTML 内进入说明和返回业务视图。
- [ ] **展示**：最终截图已打开检查，图片通过图片工具输出；额外文件入口使用绝对路径，不依赖相对路径嵌图。
- [ ] **交付**：给出唯一 HTML 成品链接、内置样式说明入口、双击打开方式、检查结果及原型边界；有未完成项就明确列出，不称为全部完成。


## 记录方式

按“检查项、实际操作/视口、观察结果、通过/失败/未验证/不适用”简要记录，不把待办勾选当作证据。遇到缺陷先修复再重查受影响项；无法验证则交付可用部分与具体限制。

交付回复给出成品绝对路径链接、样式标准入口、打开方式、实际文件大小、已完成验证和未验证项。截图由可用图片工具检查并展示；没有展示工具时提供可打开的绝对路径，不声称已向用户显示。
